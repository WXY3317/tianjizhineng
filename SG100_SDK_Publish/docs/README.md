# SG100 SDK 文档说明

本目录保存 `SG100_SDK_Publish` 的配套文档。

如果你是第一次接触这个发布包，建议先阅读仓库根目录的 `README.md`，再继续查看本目录中的详细文档。

## 阅读顺序

1. `../README.md`
   - 了解发布包包含哪些内容
   - 查看平台支持情况
   - 按最小步骤完成示例构建或 SDK 集成

2. `SG100_SDK_User_Guide.md`
   - 查看 SDK 的详细使用说明
   - 了解核心数据结构、通信模型与接口行为
   - 参考示例程序的调用方式

## 说明

- 本目录文档对应当前 `SG100_SDK_Publish` 发布包。
- 发布包不包含源码实现，文档中的接口说明以对外头文件和示例为准。
- 运行或集成 SDK 时，请保留根目录下的 `joint_angle_map.json`，不要单独删除。
