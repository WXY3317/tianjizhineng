抓取流程 2.0（按当前 scene 代码整理）

一、每次抓取的共用步骤
1. 只接收新到达、非 retained 的视觉 MQTT 消息。只处理“无遮挡正面”和“无遮挡背面”两个标签；其他标签在入队前忽略，继续等待合法标签。第一条消息根据 position1.Y 选臂：Y≥0 选左臂，Y<0 选右臂。同一次抓取的 position2 始终使用 position1 选定的手臂，即使 position2.Y 跨过零点。
2. 第一次抓取前，若 -10 cm≤position1.Y≤10 cm，先发送躯干六轴关节角 [0, 0.86725, -1.50561, -0.16162, 0, J6]：左臂抓取时 J6=-0.5 rad，右臂抓取时 J6=+0.5 rad。第二次抓取的 J6 规则见第二、三节。
3. 每次抓取都按 position1.X 判断腰部末端的 X 平移：X≤60 cm，从当前位姿沿 body_base 的 X 轴后移 20 cm；X≥75 cm，前移 20 cm；其他 X 不平移。如果本次还需要转 J6，先完成转腰，再平移 X。
4. 抓取臂以视觉目标到 position1。若运动尚未开始，逆解或关节限位被拒绝时，会依次尝试绕工具局部 Z 轴旋转的候选姿态；全部失败则停止。成功后记录旋转角和姿态矩阵。
5. position1 完成后等待配置的 interval，再保持相同法兰姿态，沿直线到视觉给出的 position2。若下降段尚未运动就因逆解或关节限位被拒绝，先在 position1 换一个工具局部 Z 角度，再重新规划下降，最多追加 4 次尝试；运动已经开始后被拒绝或尝试耗尽时停止。
6. position2 完成后，依次使能左、右夹爪并等待有效使能反馈，再让抓取侧夹爪张开到 27 mm。到位，或满足电流限制保持条件后，程序自动附着工件，无需人工调用 /scene/attach_workpiece。
7. 抓取臂回退到 position1 后，先读取该手臂最新关节反馈，只改 J1 的绝对目标角：左臂 +1.5 rad，右臂 -1.5 rad，其他六轴保持反馈角。等待完成后，无论本次是否转过 J6，都读取最新躯干反馈，只将 J4 的绝对目标角设为 0.1 rad，其他五轴保持反馈角；再次等待完成后手臂再回 pre。第一次抓取无论正面还是背面，回 pre 后都必须恢复到 arm_positions.json 的 body_photo；第二次抓取在本次转过 J6 或平移过腰部 X 时恢复。任一步缺少新鲜反馈或被控制节点拒绝时停止，不继续后续动作。

position2 缺失或为全零占位时，程序不会发送 position2，也不会自动附着工件、进入完整回退流程。自动抓取需要有效的 position2。

二、第一条目标为“无遮挡正面”
1. 第一次抓取后退回 position1，先将抓取臂 J1 送到左臂 +1.5 rad／右臂 -1.5 rad，等待完成后将躯干 J4 送到 0.1 rad，再等待完成后双臂同步到 pre；无论本次是否转过 J6 或平移过腰部 X，都必须恢复到 body_photo。随后等待第二条 MQTT。
2. 第二次固定使用与第一次相反的手臂：第一次左臂，第二次右臂；第一次右臂，第二次左臂。第二条 position1.Y 不改变选臂。第二条标签无论为正面或背面，都执行第二次抓取，不进行交接。
3. 第二次由右臂抓取时，按第二条 position1.Y 执行以下一项：
   - Y≥5：先将右臂送到关节角 [-1.5, 0.8, 2.0, -1.0, 0, 0, 0]；等待完成反馈后，保持躯干前五轴当前角度，将 J6 送到 +1.57 rad。
   - -10 cm≤Y<5：不发送手臂预备位，仅保持躯干前五轴当前角度，将 J6 送到 +0.5 rad。
   - Y<-10 cm：不转 J6，右臂直接进入抓取步骤。
4. 第二次由左臂抓取时，按第二条 position1.Y 执行以下一项：
   - Y<-5：先将左臂送到关节角 [1.5, 0.8, -2.0, -1.0, 0, 0, 0]；等待完成反馈后，保持躯干前五轴当前角度，将 J6 送到 -1.57 rad。
   - -5≤Y≤10 cm：不发送手臂预备位，仅保持躯干前五轴当前角度，将 J6 送到 -0.5 rad。
   - Y>10 cm：不转 J6，左臂直接进入抓取步骤。
5. 按第一节的 X 规则平移腰部，再抓取第二件并退回 position1。先将抓取臂 J1 送到左臂 +1.5 rad／右臂 -1.5 rad，等待完成后将躯干 J4 送到 0.1 rad，再等待完成后双臂同步到 pre；若本次转过 J6 或平移过腰部 X，再恢复 body_photo。随后躯干六轴回零，双臂同步到 home，左、右夹爪依次闭合到 0 mm，最后在 /scene/status 报告 post_grasp_completed。

三、第一条目标为“无遮挡背面”
1. 第一次抓取后退回 position1，先将抓取臂 J1 送到左臂 +1.5 rad／右臂 -1.5 rad，等待完成后将躯干 J4 送到 0.1 rad，再等待完成后第一次抓取臂单独回 pre；无论本次是否转过 J6 或平移过腰部 X，都必须恢复到 body_photo。随后等待并暂存第二条 MQTT。
2. 收到第二条后，先将躯干送到 arm_positions.json 的 body_home，再交接第一件工件：
   - 第一次左臂抓取：左臂到 left_post_grasp_joints，右臂到 right_handover_joints；右臂沿 body_base +Y 靠近 6.5 cm。右夹爪张开到 27 mm 或满足电流限制保持条件后，左夹爪闭合到 0 mm；右臂退回交接预备关节角。第一件转到右臂。
   - 第一次右臂抓取：右臂到 right_post_grasp_joints，左臂到 left_handover_joints；左臂沿 body_base -Y 靠近 6.3 cm。左夹爪张开到 27 mm 或满足电流限制保持条件后，右夹爪闭合到 0 mm；左臂退回交接预备关节角。第一件转到左臂。
3. 交接完成后，双臂同步回 pre，躯干到 body_photo，再重放暂存的第二条 MQTT。第二次固定由第一次的抓取臂抓第二件；无论第二条的标签是正面还是背面，都不再交接。
4. 第二次抓取的 J6 和手臂预备位与第二节第 3、4 步相同，按实际使用的抓取臂及第二条 position1.Y 选择：左臂在 Y<-5 时先到左臂预备位、再送 J6=-1.57 rad；在 -5≤Y≤10 cm 时只送 J6=-0.5 rad。右臂在 Y≥5 时先到右臂预备位、再送 J6=+1.57 rad；在 -10 cm≤Y<5 时只送 J6=+0.5 rad。其余 Y 不转 J6。
5. 按第一节的 X 规则平移腰部，再抓取第二件并退回 position1。先将抓取臂 J1 送到左臂 +1.5 rad／右臂 -1.5 rad，等待完成后将躯干 J4 送到 0.1 rad，再等待完成后双臂同步到 pre；若本次转过 J6 或平移过腰部 X，再恢复 body_photo。随后躯干六轴回零，双臂同步到 home，左、右夹爪依次闭合到 0 mm，最后报告 post_grasp_completed。

四、运行与异常
交接关节角在 scene.launch.py 中配置，单位为弧度。第二次抓取的 J6 ±0.5 rad 和 ±1.57 rad 均为绝对目标关节角，且仅改 J6、保留其他五轴的最新反馈角。每段运动都等待控制节点的完成反馈；双臂 pre、home 同步执行，交接及夹爪动作按顺序执行。控制拒绝、故障、反馈无效或超时会停止后续步骤，并在 /scene/status 报告原因。夹爪电流限制保持只表示达到程序继续条件，不保证工件已经夹牢。
